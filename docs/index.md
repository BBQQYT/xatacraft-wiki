# 🏠 Добро пожаловать на XataCraft

Мы — уютный ванильный сервер, который живет благодаря энтузиазму игроков и администрации. Здесь ценят честную игру и ламповую атмосферу.

!!! note ""
    Сервер работает на ваших донатах и личных средствах Тех. Админа. Благодаря вашей поддержке мы можем оплачивать мощное железо, чтобы вы играли без лагов.

***

## 🚀 Как начать играть?

!!! success "Информация для подключения"
    **IP:** `xatacraft.ru`
    
    **Версия:** `1.21.11` (вход с 1.16.5 по 1.21.11)
    
    **Платформы:** 
    ✅ Java Edition  
    ✅ Bedrock Edition

### 🎙️ Голосовой чат
Для общения на сервере мы используем **Plasmo Voice**.

*   ✅ **Plasmo Voice** — Полная поддержка (рекомендуем!)
*   ❌ **Simple Voice Chat** — Не поддерживается
