# 🏠 Добро пожаловать на XataCraft

{% hint style="success" %}
**IP:** `xatacraft.ru`\
**Версия:** `26.2` (Поддержка 1.16.5 — 26.2)\
**Платформы:** ✅ Java Edition
{% endhint %}

Мы — уютный сервер, который живет благодаря энтузиазму администрации и поддержке игроков.

### 🎙️ Голосовой чат

Мы ценим живое общение! Для разговоров на сервере используйте:

* ✅ **Plasmo Voice** — поддерживается и рекомендуется
* ❌ **Simple Voice Chat** — не поддерживается

***

## 🌍 Наши серверы

У нас есть несколько режимов для разного стиля игры:

| Режим                   | Описание                                                                                                 |
| ----------------------- | -------------------------------------------------------------------------------------------------------- |
| 🍦 **СХ (Ванилла)**     | Основной сервер для классического выживания. Чистый геймплей без лишних плагинов.                        |
| 🏚️ **ПМ (Постоянный)** | Сервер "на века". Обновлений почти не бывает, вайпов нет. Работает даже в межсезонье.                    |
| 🎪 **Event**            | Специальный сервер для ивентов. Доступ запрашивать у Тех. Админа ([@ISELLNAME](https://t.me/ISELLNAME)). |
